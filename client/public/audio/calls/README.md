# Audios de las llamadas

Pon aquí tus grabaciones (`.wav`, `.mp3` u `.ogg`) y enlázalas en `client/src/calls.ts`:

- `sayAudio` en cada ronda: lo que dice el cliente.
- `audio` en cada opción: lo que dice el jugador.
- `replyAudio` en cada opción: la reacción del cliente.

Ejemplo: `sayAudio: "vlad_r1.wav"` reproduce `public/audio/calls/vlad_r1.wav`.
