# Caras de los personajes

Pon aquí una imagen por personaje, en `.png`, con el nombre del personaje en minúsculas y sin tildes:

| Personaje | Archivo |
|---|---|
| Chidi | `chidi.png` |
| Farhan | `farhan.png` |
| Priya | `priya.png` |
| Marek | `marek.png` |
| Lucía | `lucia.png` |
| Wei | `wei.png` |
| Don Bonifacio (el jefe) | `don-bonifacio.png` |

Consejos: imagen cuadrada (por ejemplo 512×512), solo la cara, recortada, y con el fondo transparente si puedes.
Se pega delante de la cabeza como una careta. Si falta una imagen, el personaje conserva sus ojos de siempre.
